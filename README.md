# UPTE TX contract skill

This LibreChat skill helps answer questions using an inferred UC-UPTE TX
contract. The bundled text is a draft reconstruction, not an executed or
authoritative agreement or a substitute for legal advice.

## Download and install

Download [upte-tx-contract-skill.zip](https://github.com/gmerritt/upte-tx-contract-skill/releases/download/skill-latest/upte-tx-contract-skill.zip)
and upload it in LibreChat under **Skills**. The ZIP contains the
`upte-tx-contract-skill` folder, including `SKILL.md` and its references.

The [latest skill bundle release](https://github.com/gmerritt/upte-tx-contract-skill/releases/tag/skill-latest)
is automatically rebuilt when the skill folder changes on `main`. The ZIP
is a release asset, not a checked-in file. A repository maintainer can also
run the **Package skill** workflow manually from GitHub Actions.

The source reconstruction and its limitations are documented in the
[UPTE-TX-inferred repository](https://github.com/gmerritt/UPTE-TX-inferred).
